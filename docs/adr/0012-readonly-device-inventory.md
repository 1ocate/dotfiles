# ADR 0012: 외부 실행 없는 장치 상태 인벤토리

- 상태: 제안
- 범위: common, Windows 전용 프로필/터미널 조사
- 관련 작업: [작업 0016](../work/0016-readonly-device-status.md)

## 배경과 결정

장치 반영 전 흩어진 설치/연결/기록 상태를 확인해야 한다. 기존 설치기의 Check나 사용자 프로필을 실행하면 도구 시작·사용자 코드 실행·실패 시 조기 중단 때문에 완전한 읽기 전용 인벤토리를 보장하기 어렵다.

Python 표준 라이브러리와 기존 environment.py의 읽기 전용 함수를 사용해 별도 device-status 진입점을 제공한다. 도구는 PATH 존재, 연결은 해석 가능한 참조/실제 타겟, 기록은 형식·환경·호스트 유효성까지만 표시한다. 버전/기능/새 셸 검증을 완료로 추측하지 않는다. 프로필·외부 명령·설치기를 실행하거나 네트워크 API/클러스터를 직접 호출하지 않고 환경 선택/설정/진행 기록에 쓰지 않는다. Windows Documents는 OS API로 찾고 다른 환경에서는 Windows 경로를 조사하지 않는다.

출력은 사람이 읽는 요약과 JSON이며 장치 상태의 영구 스키마를 도입하지 않는다. 비밀 파일을 탐색하지 않고 알려진 상태 파일의 허용 필드만 사용한다. 정상과 누락을 한눈에 보여주되 누락을 설치 지시나 승인으로 취급하지 않는다. 파싱할 수 없는 표현식·외부 기능 검증은 확인 필요로 남긴다.

## 대안과 한계

각 설치 스크립트의 Check를 일괄 실행하는 방식은 실행 부작용/검사 범위가 달라 선택하지 않는다. 완전한 PowerShell 해석이나 모든 장치 기능의 동작 검증은 별도 단계다. 이번 인벤토리는 ADR 0011의 실제 비교를 돕는 첫 도구이며 자동 적용/로컬 상태 갱신을 대체하지 않는다.

기존 Documents/PATH/링크가 네트워크 공유를 가리키면 파일 조회 자체의 공유 접근은 발생할 수 있다. 직접 네트워크 요청을 추가하지 않는 것과 모든 네트워크 경로 접근 차단을 구분한다.
