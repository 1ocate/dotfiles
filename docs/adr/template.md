# NNNN: 결정 제목

- 상태: 제안
- 작성일: YYYY-MM-DD
- 적용 범위: common 또는 환경 ID
- 관련 작업·PR: 링크
- 채택·기각 근거: 미결정
- 대체 관계: 없음 또는 이전/후속 ADR 링크

## 배경과 문제

지속적인 결정이 필요한 이유, 제약과 확인하지 못한 사항.

## 검토한 대안

실제로 검토한 선택지와 각 비용·장점.

## 결정과 이유

선택하는 방식, 범위와 선택 근거.

## 영향과 재검토 조건

유지해야 할 동작, 비용·한계, 후속 작업과 결정을 다시 검토할 조건.

## 상태 변경·정정

시각·시간대, 변경 이유와 근거 링크. 초기 제안 이후 갱신.
