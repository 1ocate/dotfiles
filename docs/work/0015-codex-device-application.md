# 0015: Codex의 장치별 main 반영 절차 고정

- 상태: 진행 중
- 요청·배경: 한 장치에서 PR/main 반영 후 다른 장치의 Codex가 적용할 때 프로필 독립 복사·작업 누락·완료 판정 불일치가 발생했다. 공통 원본과 장치 로컬 상태를 사용한 동일 절차를 가드레일에 남긴다.
- 시작일: 2026-10-22
- 기준: main bb7871d, docs/device-apply-guardrails
- 실행 환경: windows-powershell; 지침 적용 범위는 common
- 대상: AGENTS.md, 공통 설정/AI 협업/기록 가드레일, 작업 템플릿, ADR·작업 목록
- 비대상: 설치·프로필 연결·로컬 상태 스키마 변경·자동 적용 엔진 구현·보안 설정 변경
- 관련 ADR: [ADR 0011](../adr/0011-codex-device-application.md)
- 관련 PR: 제출 후 연결

## 분석과 계획

기존 가드레일에 환경 선택·원본 loader·로컬 검증 기록은 있지만 PR 작성과 다른 장치의 main 반영을 연결하는 필수 적용 명세가 없다. environment.py는 선택/일부 연결을 점검하며 구성요소별 자동 갱신 엔진은 구현돼 있지 않다. 현재 장치의 미커밋 작업·다른 PR은 보존한다. main 갱신, 명세/실제 상태 비교, 최소 적용, 기능 검증, 구성요소별 기록·재개를 고정하고 승인 범위를 확대하지 않는다.

공통 절차 원문은 setup-guardrails에 두고 AGENTS/ai-workflow에서 연결한다. 변경별 명세는 기존 목표별 작업 기록에 두어 별도 변경 로그를 중복 관리하지 않는다. 기존 PR의 명세 부재·기록 없음·부분 실패·잘못된 loader·GUI 미확인 시나리오를 문서로 추적한다. 상대 링크/앵커·diff와 기존 지침 충돌을 검토한 뒤 PR로 제출한다.

## 검증과 남은 일

문서 검증·독립 리뷰·PR 제출이 남았다. 현재 장치나 타 장치의 적용·이전은 수행하지 않으며 구현되지 않은 자동화를 완료로 표현하지 않는다.

## 다른 장치 적용 명세

common의 Codex 지침 변경만 포함한다. main 갱신 후 AGENTS.md와 연결된 장치 반영 절차를 읽고 따른다. 설치·프로필 이전·로컬 기록 스키마 변경은 이번 PR의 적용 작업이 아니다. 기존 실행 중인 대화에서는 갱신된 지침을 다시 읽는다. 검증은 상대 링크/앵커·원본 코드와 문서 범위 일치·진행 시나리오 대조다. 실제 설치 자동화의 기능 검증으로 취급하지 않는다.


## 진행·검증 결과

2026-10-22 KST: AGENTS/AI workflow에서 공통 가드레일의 장치 반영 절차로 연결하고, 작업 템플릿·PR 검토 기준에 적용 명세를 추가했다. 신규 ADR은 제안 상태이며 실제 설치/자동화 구현은 하지 않았다. 로컬 기록 없음·과거 PR 명세 없음·부분 실패·다른 체크아웃 loader·GUI 확인 대기·선택하지 않은 기능의 시나리오를 문서 순서와 대조해 진행/중단/재개 기준을 확인했다. 이는 실제 장치 실행 검증이 아니다.

Windows 네이티브에서 변경 문서 9개의 상대 링크/앵커 91개와 git diff --check를 통과했다. 충돌 표식·의도하지 않은 타 언어 문구 검색은 일치 항목이 없었다(rg exit 1). 독립 읽기 전용 리뷰에서도 승인 확대·기존 상태 보존·프로필 일관성·미구현 구분의 차단 문제는 없었다. root의 기존 사용자 문서/lockfile/폰트와 PR #25 로컬 원본 변경은 보존했다. PR 리뷰와 병합은 남았다.
