# NNNN: 작업 목표

- 상태: 계획
- 요청·배경: 작업이 필요한 이유와 근거
- 시작일: YYYY-MM-DD
- 기준: main 커밋, 작업 브랜치
- 실행 환경: 환경 ID
- 적용 범위·비대상: 대상 파일·기능과 제외 사항
- 관련 ADR: 링크 또는 새 결정이 필요하지 않은 이유
- 관련 PR: 제출 후 갱신

## 분석과 미확인 사항

현재 동작·문제와 추가 확인이 필요한 내용.

## 계획과 완료 조건

단계별 산출물, 검증 범위·방법과 완료 조건. 계획 변경 시 이유를 로그에 남긴다.

## 진행 로그

| 시각(시간대 포함) | 이유·수행 내용 | 결과·근거 | 다음 일 |
| --- | --- | --- | --- |
| YYYY-MM-DD HH:mm TZ | 내용 | 링크·결과 | 남은 일 |

| 대상 커밋 또는 diff | 환경·검사 종류 | 명령·시나리오 | 결과·한계 |
| --- | --- | --- | --- |

## 남은 일과 종료 근거

미검증 범위·다음 단계·후속 작업 링크. 완료 시 산출물과 필요한 PR의 병합 근거.
