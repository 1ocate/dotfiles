## 분석과 계획

기존 bootstrap은 기본 아니오로 질문하고 비대화형에서는 등록하지 않는다. 기존 연결 로직은 바로가기 대상·인수·작업 경로를 비교하고 불일치 시 백업한다. 이 로직을 재사용해 현재 장치 등록만 수행하고 bootstrap 전체는 재실행하지 않는다.

계획: 로그인 등록 기본값 변경 → 기존 선택 검사 갱신 및 PS5.1/7 검사 → 실제 바로가기 생성·재실행 불변 확인 → 통합 검토·PR. 다음 로그인, GUI/IME 및 새 PC 전체 설치는 미검증으로 구분한다. 지속적인 결정과 현재 호스트 적용 상태는 별도로 기록한다.
