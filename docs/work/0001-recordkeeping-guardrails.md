## 분석과 미확인 사항

기존 README·환경 방향·설치 가드레일에는 날짜별 평가와 실행 결과가 있고, 협업 지침에는 Git·PR 기록 규칙이 있다. 결정의 대안·선택 이유와 목표별 계획·진행 결과를 연결하는 규칙은 없다. `.local/setup-state.json`은 장비별 실제 적용 상태여서 프로젝트 작업 로그의 원본으로 사용하기 어렵다.

루트 체크아웃에는 기존 미커밋 Windows 설정 변경이 있어 보존했다. 문서 변경만 독립적으로 검토하기 위해 최신 main 기반의 별도 worktree를 사용한다. 과거 Windows 실행 시각·전체 결과를 이 기록으로 재구성하지 않는다.

## 계획과 완료 조건

1. ADR·작업 로그·사용 지침·PR·로컬 상태의 원본과 작성 기준을 정의한다.
2. 목록·템플릿과 이번 결정·작업 기록을 작성하고 AGENTS·README·협업/설치 가드레일에서 연결한다.
3. 상태·권한 기준의 충돌, 링크, UTF-8 내용과 diff를 검증하고 독립 리뷰 후 별도 PR로 제출한다.
4. 이 PR이 main에 병합되면 Windows PR #7에서 main 통합과 해당 작업의 기록 정리를 진행한다. 병합 전에는 완료나 ADR 채택을 주장하지 않는다.

문서가 기존 자율 진행·설치 승인·사용자 변경 보존 기준과 충돌하지 않고 검증과 리뷰를 통과해야 제출할 수 있다. 완료 조건은 이 문서 PR의 병합 확인이다. Windows 구현 검증은 이 작업의 완료 조건에 포함하지 않는다.
